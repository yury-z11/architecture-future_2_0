Apache Spark — универсальный фреймворк для распределённой обработки больших данных. Поддерживает пакетную и потоковую обработку, ML и SQL. Стандарт де-факто для ETL-пайплайнов в Data Lakehouse.

*Бизнес-сценарии:*
- Замена медленных SQL Server запросов: обработка сотен ТБ за минуты вместо часов.
- ETL-пайплайны для загрузки событий из Kafka в Delta Lake.
- Обучение ML-моделей на исторических данных клиник.
