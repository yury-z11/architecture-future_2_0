PostgreSQL — реляционная база данных с широкими возможностями. Open source, требует только инфраструктурных вложений.

*Бизнес-сценарии:*
- Замена MS SQL Server для оперативных OLTP-нагрузок доменов (клиники, финтех).
- Хранение метаданных пайплайнов, конфигураций, пользовательских профилей.
- Операционное хранилище с быстрыми транзакционными запросами.
