Kafka Streams — лёгковесная библиотека для потоковой обработки, встроенная в приложение без отдельного кластера. Подходит для простых сценариев: фильтрация и агрегация событий.

*Бизнес-сценарии:*
- Простая фильтрация событий из доменов на уровне сервиса.
- Оценка как более лёгкой альтернативы Apache Flink для несложных пайплайнов.
