Apache DataFusion — расширяемый движок выполнения запросов на Rust с Apache Arrow как внутренним форматом. Позволяет строить специализированные аналитические инструменты.

*Бизнес-сценарии:*
- Исследование как встраиваемого SQL-движка для лёгких аналитических задач без развёртывания кластера.
