Trino (ex. PrestoSQL) — распределённый SQL-движок для интерактивных федеративных запросов к разнородным источникам без перемещения данных.

*Бизнес-сценарии:*
- Единая точка доступа для BI-инструментов (Power BI) к данным в MinIO, ClickHouse, PostgreSQL.
- Федеративные запросы для Self-Service портала: объединение данных из разных доменов.
- Ускорение разработки отчётов без необходимости физически перемещать данные.
