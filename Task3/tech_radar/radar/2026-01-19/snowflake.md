Snowflake — облачное хранилище данных как сервис с разделением вычислений и хранилища, автоматическим масштабированием и поддержкой стандартного SQL.

*Бизнес-сценарии:*
- Облачное аналитическое хранилище для замены MS SQL Server 2008.
- Масштабирование отчётности без роста затрат на инфраструктуру.
- Единая платформа для данных финтех, клиник и головного офиса.
